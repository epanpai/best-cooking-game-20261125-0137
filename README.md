**Dapur Kilat — Warung Kilat.** You are the head chef of a fast Indonesian street-food stall. Orders land on the board with a patience timer: grab ingredients from the crates, chop them on the board (hold Space), cook them in the wok, assemble the dish on the plating table, and serve it at the window before the ticket expires. Fast serves earn tips, back-to-back serves build a combo multiplier, and the last 30 seconds of the shift turn into a service rush. Static files, no network, keyboard + mouse, with synthesized sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or just open `game/index.html` from any static server. `WASD` / arrows move, `E` uses a station, hold `Space` to chop, `X` clears the plate, `P` pauses, `M` mutes. Clicking a station walks the chef there and uses it.

## Menu

Nasi Goreng, Mie Goreng, Ayam Geprek, Soto Ayam, Telur Dadar, Nasi Ayam — each a different combination of rice, noodles, chicken, egg, greens and chilli, each needing its own chop/cook route through the kitchen.
